# YT Quay v1.0.0-pre.1

Kotlin製のAndroid向けyt-dlpアプリ、初回プレリリースです。

## インストール

Android 10以降。通常のスマートフォンでは **arm64-v8a.apk** を選んでください。ARMv7版とx86_64版も用意しています。

## 機能

- URLの貼り付け・他アプリからの共有で動画と音声を保存
- 720p・1080p・最高画質、元の音声形式・MP3 192 kbpsを選択
- 通知で進捗を確認、キャンセル、保存履歴から開く・共有
- yt-dlpをアプリ内で更新。Stable／Nightly、自動更新のON/OFF、直前の版への復元に対応
- 更新ファイルのSHA-256照合と差し替え後の起動確認
- Python・FFmpeg・QuickJSを同梱。保存先は `Download/YTQuay`

旧ClipDock版からは同じ署名・アプリIDで上書き更新できます。以前の保存ファイルは `Download/ClipDock` に残ります。

## 確認状況・制約

- releaseビルド、ユニットテスト9件、Lint（エラー0）、3種類のAPK署名・zip alignmentを確認済みです。
- **Android実機での起動・保存・更新・復元は未確認**です。動作確認用のプレリリースとして公開します。
- 同梱yt-dlpは2026.08.19。yt-dlp本体はアプリ内で更新できます。
- Python・FFmpeg・QuickJSの更新にはAPKの更新が必要です。
- 1件ずつ保存。プレイリスト全件、Cookie・ログイン、DRM処理には未対応です。

ビルドとテストの記録は `docs/VERIFICATION.md`、APKのハッシュは添付の `SHA256SUMS` を参照してください。
